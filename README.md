🌍 Wanderly – Explore the World

Wanderly is a Travel & Tourism website designed to showcase beautiful destinations, exciting travel experiences, and holiday packages.

✨ Features

- Attractive homepage
- Beautiful travel destinations
- Holiday packages
- Popular travel experiences
- Customer testimonials
- Contact information
- Responsive design
- Smooth CSS animations

🛠️ Technologies Used

- HTML
- CSS
- CSS Flexbox and Grid
- CSS Animations
- Media Queries

📂 Project Structure

- "index.html" – Website structure
- "style.css" – Website styling
- "images/" – Website images

🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open "index.html" in your browser.
